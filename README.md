# シフト帳

シフト表の写真を撮るだけで、**自分のシフトだけ**を読み取ってカレンダーに登録してくれるアプリです。
シフトボードのように、カレンダー表示・勤務先ごとの色分け・見込み給料の計算ができます。

## できること

- **写真で取り込み** — シフト表を撮影 (または写真を選択) すると、Claude が表の中から自分の名前の行/列を探し、勤務日と時間を読み取ります
  - 苗字だけ・カタカナ・あだ名などの「別表記」にも対応
  - 「早」「遅」「A」のような記号は、写真内の凡例か、設定で登録した記号表から時間に変換
  - 「17-L (ラスト)」のように時間が分からないマスは、手入力をうながします
  - 登録済みのシフトと同じものは自動で外します
  - 表が複数枚に分かれていてもまとめて読み取れます
- **カレンダー** — 月表示、日付をタップしてシフトの追加・編集・削除
- **一覧・給料** — 月ごとの出勤日数・勤務時間・見込み給料 (勤務先ごとの時給、休憩、夜勤に対応)
- **書き出し** — `.ics` で Google カレンダー / iPhone のカレンダーへ
- **バックアップ** — JSON で保存・復元

## 使い方

1. 「設定」で **自分の名前** と **Anthropic API キー** を入力します ([キーの発行](https://console.anthropic.com/settings/keys))
2. 必要なら勤務先 (色・時給) とシフト記号を登録します
3. 「写真で取込」でシフト表を撮影 → 「シフトを読み取る」
4. 読み取り結果を確認・修正して「カレンダーに追加」

スマホでは、ブラウザの「ホーム画面に追加」でアプリのように使えます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ユニットテスト
npm run build    # dist/ に本番ビルド
```

`main` に push すると GitHub Actions で GitHub Pages に公開されます
(リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください)。

## しくみ・注意

- React + TypeScript + Vite のサーバー不要のアプリです。データはすべて **ブラウザの localStorage** に保存されます。
- 写真の読み取りは Claude API (既定は `claude-opus-5-5`) の画像認識と構造化出力を使っています。プロンプトは `src/lib/extract.ts` にあります。
- API キーは端末内に保存され、ブラウザから Anthropic に直接送信されます。個人で使う前提の設計です。
  ほかの人にも使ってもらう場合は、キーをサーバー側に置くプロキシを用意してください。
- 読み取り 1 回あたり十数円〜数十円程度の API 利用料がかかります (写真の枚数・モデルによって変わります。設定で安いモデルも選べます)。
